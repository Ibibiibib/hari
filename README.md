# Habit Quest — трекер привычек (Android)

Тёмный трекер привычек с сериями, уровнями из Minecraft и ежедневным напоминанием.

## Сборка
1. Открой папку проекта в Android Studio (Hedgehog или новее).
2. Дождись синхронизации Gradle.
3. Run ▶ на эмуляторе/устройстве с Android 10+.

## Правила серии (реализованы в `logic/StreakCalculator.kt` + `MainViewModel`)
- Можно отмечать **только сегодняшний день** (в коде пишется только `LocalDate.now()`; вчерашний день и завтра недоступны в UI, API и виджете).
- Серия растёт, пока подряд выполняются **ВСЕ** привычки.
- 🔥 Огонь в углу появляется после **3 полных дней подряд**, рядом — количество дней серии.
- **Воскрешение** серии — 1 раз в месяц (кнопка появляется, только когда серия сгорела).
- Если за месяц **2 и больше неполных дней** (вчера и ранее) — серия сгорает и начинается с нуля.
- Привычка участвует в статистике только с даты своего создания (нельзя «задним числом» накрутить серию).

## Уровни (Minecraft, каждый сложнее)
Дерево (0) → Камень (300) → Железо (800) → Золото (1600) → Алмаз (3200) → Незерит (6000).
XP: +10 за отметку, +25 за полный день.

## Уведомление
Каждый день в 21:00 (WorkManager):
- Заголовок: «не забывай про себя»
- Текст: «ТЫ самое важное что есть у тебя»

## Виджет
Виджет «Сегодня» похож на заметку: список привычек с чекбоксами, отметка прямо с рабочего стола.

## Перед публикацией
- Замени `android.R.drawable.ic_dialog_info` в `DailyReminderWorker` на свою иконку уведомлений.
- Добавь свой `@mipmap/ic_launcher` (сейчас используется дефолтный).
- Проверь `applicationId` в `app/build.gradle.kts`.
